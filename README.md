# Dissertation: Model Repo
Model architecture, code and weights for my MSc Dissertation Project

## Setup
Create a fresh python virtual environment and run `install.py` to install all the required dependencies. You can also setup the dependencies manually by looking at full_requirements.txt.

## Training
Python bench supports training, validation and evaluation for different methodologies: Conventional classification (fine-tuning and training from scratch), Siamese Few-Shot training, Knowledge Distillation. Refer to the code and `scripts/next.sh` for parameters and sample running commands to see.
